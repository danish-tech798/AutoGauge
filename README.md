# Used Car Price Prediction — Final Year Project

## VS Code Setup (do this first)

1. **Open the folder in VS Code**
   ```
   code project/
   ```
   (or File → Open Folder → select `project/`)

2. **Install the Python extension** — VS Code will prompt you automatically
   the first time you open a `.py` file, since `.vscode/extensions.json`
   recommends it. Click "Install" when prompted (also installs Pylance +
   Jupyter support).

3. **Create a virtual environment** — open the VS Code terminal
   (`` Ctrl+` `` / `` Cmd+` ``) and run:
   ```
   python -m venv .venv
   ```
   VS Code will detect it and prompt "Select as interpreter" — click yes.
   If it doesn't prompt, press `Ctrl+Shift+P` → "Python: Select Interpreter"
   → choose `.venv`.

4. **Activate it and install dependencies:**
   - Windows: `.venv\Scripts\activate`
   - Mac/Linux: `source .venv/bin/activate`
   ```
   pip install -r requirements.txt
   ```

5. **Download the dataset** and place it at `data/raw_cars.csv`:
   - https://www.kaggle.com/datasets/nehalbirla/vehicle-dataset-from-cardekho
   - or https://www.kaggle.com/datasets/manishkr1754/cardekho-used-car-data

6. **Run the preprocessing script** — either:
   - Press `F5` (uses the "Preprocess Data" config in `.vscode/launch.json`), or
   - Terminal: `python src/data_preprocessing.py --input data/raw_cars.csv --output data/processed_cars.csv`

## What the script does
- Auto-detects which of the two common CarDekho CSV schemas you downloaded
- Splits `name` into `brand` + `model`
- Converts unit-suffixed columns (`23.4 kmpl`, `1248 CC`, `88 bhp`) into clean floats
- Fixes impossible values (negative km, car age > 40 yrs, 0 km driven)
- Imputes missing numeric values with the median (robust to outliers)
- Engineers new features:
  - `car_age`, `age_squared`, `is_new_ish` — capture non-linear depreciation
  - `km_per_year` — flags odometer inconsistencies
  - `brand_tier` (luxury / premium / economy) — brands depreciate differently
  - `power_per_cc` — performance proxy
  - `owner_count` — numeric ordinal instead of text
  - `price_log` — log-transformed target (car prices are right-skewed)
